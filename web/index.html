Changement automatique

Le thème d'une image locale est le nom de son sous-dossier ; celui d'une image téléchargée est le thème de sa source.

Le programme n'est pas installé : le démarrage utilisera le dossier actuel. Lancez ./install.sh pour une installation stable.

Images locales
Images téléchargées

Type « Automatique » : l'adresse peut pointer vers une image, une page de miniatures, un flux RSS ou un fichier JSON ; les images (et les liens vers leurs pages de détail) sont repérés automatiquement. Unsplash, Pexels et Pixabay passent par leur API officielle : une clé gratuite est nécessaire. « Max par jour » est la seule limite : nombre maximal d'images téléchargées chaque jour pour cette adresse. Les images s'accumulent donc jusqu'à ce que vous les supprimiez dans la galerie.

Filtre de dimensions

Les dimensions tiennent compte de l'orientation EXIF des photos. « Largeur souhaitée » : quand un site propose plusieurs formats, on prend le plus grand qui ne la dépasse pas (évite les fichiers 8K énormes).
